# 🚀 실시간 탐구 학습지 생성기 (i wanna Dash ⛷️)

> **Vite와 Firebase SDK v10를 활용한 실시간 탐구 활동지 생성 및 모니터링 플랫폼**  
> 교사가 웹 시뮬레이션(GeoGebra, PhET 등)과 탐구 질문을 연동하여 실시간으로 학습지를 생성하고, 학생의 제출 데이터를 동기화 하여 볼 수 있습니다.

---

## 📖 서비스 작동 순서 & 핵심 기능

### 1단계: 수업 자료 및 질문 구성 (교사)
교사가 수업에 활용할 교안 자료와 질문들을 맞춤형으로 설정합니다.
* **자료 다양화 (탭별 구성)**: 웹 시뮬레이션(GeoGebra, PhET 등), PDF 교안, 이미지, 백지/모눈/좌표평면 추가 및 가로/세로 레이아웃으로 결합.
* **자유로운 문항 설계**: 주관식 서술형 및 객관식 선택형 탐구 질문 맞춤 생성.
* **학습 추적 옵션**: 탭별 독립 / 전체 필기 모드 선택, 탐구 소요시간 타이머 설정 지원.
* **수업방 제목 및 ID 분리**: 언제든 수정 가능한 수업방, 링크/QR 불변 고정.

### 2단계: 수업방 배포 및 링크 공유 (교사)
생성한 방을 클라우드에 배포하고 접속 주소를 전달합니다.
* **QR 코드 자동 생성**: 모바일/태블릿 카메라로 즉각 입장할 수 있는 QR 코드 제공.
* **교사용/ 학생용 이중 링크 관리**: 학생 탐구 활동지/ 교사 모니터링 및 대시보드.

### 3단계: 학생 실시간 탐구 및 제출 (학생)
공유받은 링크로 접속하여 자료를 탐구하고 활동지를 작성합니다.
* **캔버스 드로잉,필기**: 시뮬레이션 및 교안 위에 자유롭게 필기(펜/형광펜/지우개/투명도/두께) 가능.
* **화면 캡처 및 파일 첨부**: 필기 내용 및 시뮬레이션 화면 캡처 및 이미지 파일 첨부(최대 500KB) 지원.
* **복사/붙여넣기 탐지**: 비정상적인 외부 텍스트 붙여넣기 횟수 및 내용 자동 기록.

### 4단계: 실시간 동기화 모니터링 & 수합 (교사)
학생들이 제출한 탐구 결과를 실시간으로 확인하고 관리합니다.
* **실시간 대시보드**: 새로고침 없이 학생 학번/이름/답안/필기 캡처/소요시간이 실시간으로 동기화되어 적재(학번순 정렬).
* **치팅/표절 하이라이트**: 복사-붙여넣기 이력이 있는 답안 영역 시각적 강조 표시.
* **엑셀(CSV) 다운로드**: 학생들의 전체 답안 데이터를 문항별로 정돈된 엑셀 호환 CSV 파일(UTF-8 BOM)로 다운로드.
